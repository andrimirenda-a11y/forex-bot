Collega GitHub

Per salvare le impostazioni l'app scrive il file data/settings.json nel tuo repository. Serve un token GitHub (lo incolli una volta sola, resta salvato solo su questo telefono).

Come creo il token?
  1. Apri github.com → foto profilo → Settings → Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → scegli forex-bot.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Genera, copia il token (inizia con github_pat_) e incollalo qui sotto.

Azzera conto virtuale

Al prossimo giro il bot chiude le posizioni virtuali e fa ripartire il conto dal capitale iniziale impostato qui sopra. Nessun soldo vero è coinvolto.

Comandi Telegram

Puoi controllare il bot anche dalla chat Telegram:

  • /stato conto, equity e stato del bot
  • /posizioni posizioni aperte
  • /statistiche risultati dei trade chiusi
  • /capitale 2000 imposta il capitale iniziale
  • /leva 30 imposta la leva (1:30)
  • /rischio 1 rischio per trade in %
  • /pausa nessun nuovo trade
  • /riprendi riattiva i nuovi trade
  • /stop chiude subito tutte le posizioni
  • /aiuto elenco dei comandi
